# Dataset Description

## Overview

The AstraMesh Security Evaluation Dataset contains 721 prompts designed to evaluate secure agricultural AI systems.

The dataset contains both adversarial and benign agricultural queries.

## Category Distribution

| Category | Count |
|-----------|--------|
| Prompt Injection | 180 |
| Data Poisoning | 180 |
| Jailbreak | 180 |
| Benign Queries | 181 |

## Languages

The dataset includes:

- English
- Hindi
- Telugu
- Tamil

## Prompt Injection Patterns

- System prompt extraction
- Context leakage
- Retrieval disclosure
- Hidden instruction exposure
- Developer impersonation

## Data Poisoning Patterns

- Fake fertilizer recommendations
- Fake irrigation practices
- False government advisories
- Fabricated research findings
- Knowledge base corruption

## Jailbreak Patterns

- DAN mode
- Role-play attacks
- Safety bypass attempts
- Developer mode prompts
- Unrestricted system prompts

## Benign Query Patterns

- Fertilizer recommendations
- Pest management
- Irrigation scheduling
- Crop selection
- Disease diagnosis
